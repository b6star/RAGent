# Phase 2 Development Steps

Phase 2 - Firebase 실제 데이터 구현을 Step과 PR 단위로 관리한다.

Firebase Google 로그인은 이미 구현된 상태를 전제로 한다.

## Order

1. [Step 01 - Firebase Data Foundation](step-01-firebase-data-foundation.md)
2. [Step 02 - Project CRUD](step-02-project-crud.md)
3. [Step 03 - Members, Roles and Sharing](step-03-members-roles-sharing.md)

## Rule

- 모든 Step은 Phase 2의 Firebase 실제 데이터 범위만 다룬다.
- 앞 Step이 완료된 뒤 다음 Step으로 진행한다.
- 각 Step은 하나의 feature 브랜치와 PR을 기준으로 관리한다.
- GitHub, Notion, Cloud Functions, RAG, Gemini는 Phase 2 이후에 다룬다.
